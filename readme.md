## Дорогой Бро,вот тебе короткий гайд, как создать свой первый репозиторий
1. Первым делом установи cygwin и git-bash на своём Win11
2. Запусти обе программы

### Создай ssh ключ 
* Сгенерируй ключ через консоль в дефолтной директории .ssh
~~~
ssh keygen -t ed25519 -C "<your_email>"
~~~
* Скопируй содержимое публичного ключа
~~~
clip > ~/.ssh/id_ed25519.pub
~~~
### Зарегистрируйся на GitHub
* Перейди на github.com и пройдти регистрацию на свою почту
* Создай новый публичный репозиторий и присвой ему имя
* В настройках профиля вставь из буфер свой публичный ssh ключ
* В настройках нового репозитория скопируй путь по ssh (Quick setup -> SSH -> copy link)

### Создаём локальный репозиторий и синкаем с удаленным в гитхабе
* Создай директорию (<dir_name> это имя твоей директории)
~~~
mkdir <dir_name>
~~~
* Перейди в неё
~~~
cd <dir_name>
~~~
* Выполни инициализацию Git в локальном репозитории
~~~
git init
~~~
* Создай файл readme.md
~~~
touch readme.md
~~~
* В Windows добавь в него любой текст и сохрани
* Выполни команду для добавления новых файлов 
~~~
git add --all
~~~
* Выполни команду для коммита изменений и укажи комментарий
~~~
mkdir <dir_name>
~~~
* Выполни иницианизацию удаленного репозитория
~~~
git remote add origin <ssh_путь_удаленного_репозитория_github>
~~~
* Выполни коммит в удаленный репозиторий
~~~
git push -u origin master
~~~
### Теперь зайди в гитхаб в свой репозиторий, и проверь, появился ли новый коммит с файлом readme.md
